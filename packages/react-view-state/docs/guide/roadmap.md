# 路线图

## 已完成（0.1.0）

- `PageStateCache` / `usePageState`：模块级页面状态缓存，首帧恢复、跨卸载存活。
- `useScrollMemory`：滚动位置记忆，支持 `dom` / `delegate` 两种恢复方式与一次性消费。
- `clearViewCaches`：登出统一清理页面状态与滚动位置。
- ESM + CJS 构建、Vitest（jsdom）用例、覆盖率上报 Sonar。

## 计划中

- **持久化适配**：可选的 `sessionStorage` 后端，让页面状态与滚动位置跨刷新恢复（需要序列化边界与版本迁移约定）。
- **滚动记忆的多容器支持**：同一页面上多个独立滚动区（例如双栏详情页）的命名空间约定。
- **更多虚拟化集成示例**：除现有的网格协议外，补充列表/树形虚拟化的对齐示例。
- **调试工具**：开发态查看当前页面的缓存键、页面状态与滚动锚点。
